# 🪨📄✂️ Rock, Paper, Scissors

A simple **Rock, Paper, Scissors game in Python** where the player plays against the computer.

## 📌 About the Project

I created this project as a small test of my Python skills.

I had seen a similar program on a computer in my college and, just out of curiosity, I wanted to see whether I could **remember the logic and recreate the program myself**.

This project was also a small way for me to enjoy the **freedom of coding and experimenting with what I remember** rather than simply following a tutorial.

## 🎮 How It Works

The player chooses:

1. Stone
2. Paper
3. Scissors

The computer randomly selects one of the three choices.

The program then compares both choices and decides whether the player:

* 🏆 Wins
* 😅 Loses
* 🤝 Ties

## 🛠️ Concepts Used

This project helped me practice:

* `import`
* Python's `random` module
* `input()`
* `print()`
* `if`, `elif`, and `else`
* Variables
* Functions using `def`
* Random number generation using `randint()`
* Basic game logic
* Comparing conditions

## ▶️ How to Run

Make sure Python is installed on your computer.

Then run:

```bash
python rock_paper_scissors.py
```

Enter a number from `1` to `3` and play against the computer.
